# QQQ 未来未跌破交易日

这个 Streamlit 小工具读取本地 `../stockData/QQQ.csv`，展示 QQQ 收盘价走势，并按以下规则给曲线分成两种颜色：

- 绿色：该交易日之后，再也没有任何一天的 QQQ 收盘价低于当天收盘价。
- 橙色：该交易日之后，曾经出现过更低的 QQQ 收盘价。

颜色判定基于完整 CSV 的未来数据计算；页面里的时间范围只控制图表展示窗口，不会改变每个交易日的颜色标签。

## 运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 数据口径

当前使用 `close` 收盘价判定“未来是否跌破”。如果某天之后所有交易日的收盘价都不低于当天收盘价，该交易日会被标记为“未来未跌破交易日”。
