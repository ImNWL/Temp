# 策略对比 (`n_qqq_new`)

基于 Apple 设计语言与 TradingView 级时间轴标尺交互打造的多标的 / 策略 / 合成杠杆（如 `xQQQ`）走势对比工具。

## 核心特性

1. **多标的 + 本地策略 + 合成杠杆同图对比**
   - **正式行情数据**：自动扫描 `../stockData/*.csv`，支持在左侧栏直接输入美股代码（逗号或空格分隔）实时拉取并加入对比，支持增量更新与 2015 年起全量更新。
   - **自定义策略 CSV**：将策略回测 CSV 放入 `../stockData/` 或 `../stockData/strategies/`（包含日期列与净值/收益列），自动识别并可随时勾选对比。
   - **合成杠杆曲线**：支持以任意已加载标的为基准生成 `-5x ~ +10x` 每日再平衡合成杠杆曲线，毫秒级实时重绘。
2. **TradingView 级交互走势图与底部时间轴标尺**
   - **底部时间轴标尺（Navigator Ruler）**：支持拖拽左右手柄自由裁切起止区间、按住选区左右丝滑平移滑动、在空白区框选或单击跳转、双击复位全部历史。
   - **主图直觉手势**：支持鼠标滚轮以光标处日期为锚点平滑缩放、触控板双指水平滑动或鼠标拖拽平移、`Shift + 拖拽` 区间测距尺、双击复位。
   - **窗口首日实时动态归零**：无论拖动底部尺子、缩放平移还是切换快捷周期，所有曲线与下方「区间表现汇总」均按当前窗口首日实时归零重算。

## 启动方式

```bash
cd 股市讨论/n_qqq_new
pip install -r requirements.txt
python3 app.py
```

默认监听 `http://127.0.0.1:8501`（可通过 `--port` 指定端口，或添加 `--open` 自动打开浏览器）。
