# 多标的 / 策略 / xQQQ 收益率走势对比 (`n_qqq_new`)

一个聚焦于**走势图视觉对比**的交互工具：支持任意美股 / ETF 正式数据、用户自定义策略净值 CSV（存于 `../stockData/`）与任意基准的每日再平衡合成杠杆曲线（如 `xQQQ`）同图对比。

## 核心特点

1. **多标的 + 策略结果 + 合成杠杆统一对比**
   - **正式行情数据**：自动扫描 `../stockData/*.csv`，并支持在侧边栏直接输入美股代码（如 `SPY`、`NVDA`、`MSFT`、`SOXL` 等，支持逗号分隔批量）实时拉取并存入 `../stockData/`。
   - **自定义策略 CSV**：将策略回测生成的 CSV 放入 `../stockData/`，只要包含日期列（`date` / `日期`）与净值或收益列（`close` / `nav` / `equity` / `净值` / `cum_return` / `daily_return`），即可在侧边栏「已选股票 / 策略」中自动识别并勾选对比。
   - **合成杠杆曲线**：支持以 `QQQ` 或任意已加载标的为母本生成 `-5x ~ +10x` 每日再平衡合成曲线。
2. **围绕看图体验打磨的交互细节**
   - **快捷周期栏**：`YTD` / `近1年` / `近3年` / `近5年` / `近10年` / `全部`，每次切换自动将窗口首日归零对比。
   - **末端直接标签 + 防碰撞排版**：每条曲线右侧直接显示最新累计收益或净值倍数，无需在曲线与图例之间来回对照。
   - **聚光灯聚焦模式**：曲线较多时可高亮任意一条，其余自动退居半透明背景。
   - **主副图联动**：上方主走势图（支持线性/对数切换、历史熊市背景带）与下方紧凑水下回撤图共享 X 轴与十字准星。

## 运行

```bash
# 1. 拉取/更新默认基础行情 (QQQ / QLD / TQQQ)
cd ../stockData
python3 fetch_data.py

# 2. 启动对比工具
cd ../n_qqq_new
pip install -r requirements.txt
streamlit run app.py
```
